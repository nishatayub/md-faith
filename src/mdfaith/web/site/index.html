Evaluation harness · fact-checker

Don't trust an AI's reading of your MD run. Check it.

LLMs now explain molecular dynamics analyses, and they sound confident whether or not they are right. MD-Faith computes ground truth from the trajectory, plants known processing problems, and checks every claim against the numbers, with code rather than another model's opinion.

Three ways an AI explanation goes wrong

Plausible but wrong numbers

Values read off a plot, rounded aggressively or invented. A sentence like "mean RMSD is about 2 Å" is easy to write and hard to notice when it is really 4.4 Å.

Artifacts read as physics

A domain wrapped across the periodic boundary makes RMSD spike. An explanation that reports a "large conformational change" has explained a processing error.

Mechanisms nobody measured

"Caused by hinge motion" sounds expert. Nothing in an RMSD curve establishes a mechanism, so such claims are flagged unless they cite computed evidence.

How it works

Every verdict is computed from coordinates. No LLM decides what is true.

  1. TrajectoryPublic systems only
  2. QC gateWrapping, fitting, frame order
  3. Ground truthRMSD, RMSF, Rg, contacts, H-bonds
  4. AI explanationPlot, table or tool agent
  5. Claim extractionNumeric, ranking, temporal, causal
  6. VerifierTolerance-based, in code
  7. Evidence reportPer-sentence verdict and proof

What's inside

Trajectory QC

Detects broken backbones, frame discontinuities, unfitted frames and scrambled order before anyone interprets the data.

Ground truth

RMSD, RMSF, radius of gyration, contacts and distance-and-angle hydrogen bonds, cross-checked against MDAnalysis.

Planted traps

Wrapped domains, shuffled frames and unfitted trajectories with known consequences, so you can test whether an AI notices.

Claim verifier

Numeric, ranking, temporal and causal claims, each with explicit tolerances and its own verdict label.

Evidence-linked reports

Every sentence tagged, with the computed value, the tool that reproduces it and the definition behind it.

Benchmark runner

Conditions × models × artifacts × seeds, stored in SQLite, with bootstrap intervals on every rate.

Web app and API

Trajectory lab, fact-check playground, run manager and results dashboard, all backed by a documented REST API.

Model adapters

A hosted-model adapter and a free local Ollama adapter behind one small interface. Refusals are recorded, never hidden.
