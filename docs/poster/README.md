# Poster

`poster.html` is a print-ready A1 landscape template. Open it in Chrome or Edge, choose *Print*, set the paper size to
A1 (or A2 with "fit to page"), margins *none*, background graphics *on*, and save as PDF.

Regions marked `PLACEHOLDER` stay visibly dashed until real results replace them; see `../FINDINGS_TODO.md`. Figures
under `../figures/` that come from simulated explainers carry a DEMO stamp inside the image and must not appear on a
final poster.
