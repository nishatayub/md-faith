MD-Faith: check the AI's reading of your MD run

An evaluation harness that computes ground truth from trajectories, plants known processing problems and verifies every claim an LLM makes, with code rather than a second model.

Why

  • LLMs now explain MD analyses and sound equally confident when wrong.
  • Numbers get read off plots; periodic-boundary artifacts get reported as conformational change; mechanisms get asserted without evidence.
  • No benchmark scores such explanations against trajectory-computed ground truth.

Question

Which claims in an LLM's explanation of an MD analysis are faithful to the trajectory, and does giving the model tools rather than a picture or table reduce unfaithful claims, including when the trajectory has a processing problem?

Verdicts

Supported matches the computed value
Contradicted checkable and wrong
Artifact misread processing error presented as physics
Unsupported mechanism without cited evidence

Method

  • Ground truth: RMSD, RMSF, Rg, contacts, distance-and-angle H-bonds (cross-checked against MDAnalysis).
  • Traps: wrapped domain, shuffled frames, unfitted frames.
  • Conditions: image only, table only, tool agent, QC-gated agent.
